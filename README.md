# Order App

Table-side ordering for restaurants in Dar es Salaam. Diners scan a QR code, join a shared table with a short code, order from their own phones, and split the bill. Orders route to separate kitchen, bar and grill screens; the waiter who accepts a table gets that table's "Call waiter" and "Bill please" alerts.

Pilot menu: Crafty Dee's Brewpub and Beer Garden (prices taken from public menu photos; confirm before use).

## Status

- `index.html` — single-device clickable prototype (all screens on one phone, tabs switch between them).
- Next: live multi-phone version with a shared realtime database (Firebase).
